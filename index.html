Exhibit C · ML · platform

Account2Vec — fleet telemetry, turned into a
reusable ML primitive.

Every ML effort in Azure Storage was rebuilding features from the same raw telemetry. Account2Vec is an unsupervised autoencoder + FAISS index that compresses ~80–100 behavioral features per account into a dense embedding, then extends hierarchically to subscriptions and customers — so similarity search, segmentation, anomaly detection, forecasting, and LLM-reasoning teams all build on one shared representation.

§03 — Judgment

Four calls I'd defend in the interview.

Senior hires aren't judged on tools — they're judged on decisions under ambiguity. Here are four of mine, with the trade-off and the outcome. Each comes with the question you should grill me on.

Call 01architecture

Fired the framework.

The incident agent started on LangChain / LangGraph. Debugging through five layers of someone else's abstraction was slower than owning the loop — so I replaced it with a hand-rolled planner / executor: full LLM tracing to Kusto, 429-storm retry, context compaction we control, concurrent tool dispatch.

→ faster iteration, traceable failures, an agent on-call actually trusts

ASK ME ABOUT: compacting a 200K context without losing the investigation thread

Call 02quality

Evals before demos.

The MCC copilot didn't meet a single real user until a golden-set eval harness, guardrails, and PII-aware prompts existed. Demos earn applause; evals earn production. The harness now gates every prompt and model change like CI.

→ 8+ teams on one surface, leadership quoting its numbers unprompted

ASK ME ABOUT: building golden sets that catch agent regressions before users do

Call 03platform

A model is not a platform.

Account2Vec could have shipped as one team's similarity model. Instead I named the abstraction, wrote the design doc, and built the drift / coverage / staleness plumbing that makes other teams safe to depend on it — account, subscription, and customer tiers included.

→ 5+ downstream consumers building on one representation

ASK ME ABOUT: what it takes for another team to bet their roadmap on your embeddings

Call 04trust

Trust is a number.

Revenue data is only useful if Finance can't break it. I rebuilt partner attribution to <1% variance vs. Finance (~$45M/mo, ~4× coverage), then shipped the data-quality service — 76 tests, 4 security gates — that caught an ~88% upstream row collapse before a single dashboard went wrong.

→ GM / CVP-level reliance; PMs accept the dashboards as governed source

ASK ME ABOUT: detecting silent data failures nobody filed a ticket for
