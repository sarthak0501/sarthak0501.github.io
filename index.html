04 — Case study · foundational ML platform
ML · Platform

Account2Vec — turning fleet telemetry into a
reusable ML primitive.

Every ML effort in Azure Storage was rebuilding its own features from the same raw telemetry. Account2Vec is an unsupervised autoencoder backed by a FAISS index that compresses ~80–100 behavioral features per account — across capacity, transactions, errors / latency, configuration, and authentication patterns — into a dense embedding (candidate dims 8–128). It then extends hierarchically to subscriptions and customers (TPIDs), so fleet-scale similarity search, segmentation, embedding-drift anomaly detection, forecasting, and LLM-reasoning teams all build on one shared representation.
